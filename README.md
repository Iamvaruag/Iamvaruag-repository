# Gaurav Bhambale — AI + Full Stack Portfolio

Dark-premium responsive portfolio built with Next.js App Router, TypeScript, Framer Motion, and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open http://localhost:3000

## Before publishing
- Confirm that `gauravbhambale@gmail.com` is the best public contact email.
- Add a real resume PDF to `public/resume.pdf` and add a download button when your resume is ready.
- Add the actual Valor Arena repository URL if it is public. Its current button links to your GitHub profile to avoid inventing a repository URL.
- Add live deployment URLs for projects when available.
- Check that all listed skills accurately reflect your experience.

## Deploy
Push the project to GitHub and import it into Vercel. The default Next.js build settings should work.
